CSS grid layout

The CSS grid layout module is great for dividing a page into sections and defining the size, position, and layering of HTML elements.

Like tables, grid layout allows alignment of elements in columns and rows, but offers more flexibility, including overlapping elements.

Grid layout in action

The example shows a three-column grid with rows created at a minimum of 100 pixels and a maximum of auto. Items are placed using line-based placement. 

<div class="wrapper">
  <div class="one">One</div>
  <div class="two">Two</div>
  <div class="three">Three</div>
  <div class="four">Four</div>
  <div class="five">Five</div>
  <div class="six">Six</div>
</div>

This sample uses display, grid-template-columns, grid-template-rows, and gap to create the grid, and grid-column and grid-row to position items.
