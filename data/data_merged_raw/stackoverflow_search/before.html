I've set up a basic C++ project on VSCode on Windows. My main.cpp program looks like this:

#include <random>

using namespace std;

int main() {
  default_random_engine generator();
  uniform_int_distribution<int> distribution(0, 10);
  printf("%d", distribution(generator));
  return 1;
}

However, when I compile and run this program, I get the error:
